
## 💻 Progetti principali

### 🔐 Corvo – Auditing & Monitoring System
Sistema sviluppato durante la tesi magistrale per supportare attività di auditing e monitoraggio.  
Architettura distribuita con componenti backend e agenti per raccolta dati.

- **Tech:** Java (Spring Boot), Angular, Python  
- **Focus:** auditing, sicurezza, raccolta e gestione dati  
- **Cosa dimostra:** progettazione di sistemi complessi, backend, integrazione sicurezza  

🔗 https://github.com/MariusBerinde/corvo.git  


---

### ⚡ Parallel QuickSort & MergeSort (HPC)
Implementazione parallela degli algoritmi di ordinamento in ambiente HPC.

- **Tech:** C, MPI, OpenMP  
- **Focus:** parallel computing, performance  
- **Cosa dimostra:** ottimizzazione, programmazione concorrente  

🔗 https://github.com/MariusBerinde/parallele_quick_marge_sort.git

### 🧠 Simplesso su rete (Shortest Path)
Implementazione del simplesso su rete per il calcolo del percorso minimo.

- **Tech:** C/C++  
- **Focus:** algoritmi, ottimizzazione  
- **Cosa dimostra:** basi solide di algoritmi e strutture dati
